# Haryana Hydro-Economic Model

Interactive hydro-economic model for evaluating crop allocation, irrigation water use, profitability, and groundwater stress across Haryana.

## Project

This project explores the relationship between agricultural crop allocation, irrigation water availability, crop profitability, and groundwater stress across Haryana.

The interactive website allows users to explore district-wise results and examine the effects of reduced irrigation water availability on crop yield, water withdrawal, and profit.

## Methodology

The analysis uses hydro-economic optimization and the FAO-33 Yield Response Factor (Ky) approach to assess crop-water relationships and water-saving scenarios.
